E-Commerce Sales Analytics — Superstore

📌 Project Overview

This project analyzes the Sample Superstore dataset to identify sales, profit, customer, product, and regional performance insights.

The project uses **Python, SQL, and Power BI** to demonstrate an end-to-end data analytics workflow.

🛠️ Tools & Technologies

- Python
- Pandas
- Matplotlib
- Jupyter Notebook
- MySQL
- Power BI
- GitHub

 📊 Project Workflow

 1. Python — Exploratory Data Analysis

Performed data cleaning, exploration, aggregation, and visualization using Pandas and Matplotlib.

Key analyses:
- Sales and profit by category
- Sales and profit by region
- Top 10 products
- Discount vs. profit

2. SQL — Data Analysis

Used MySQL to analyze the Superstore dataset.

SQL techniques included:
- Aggregations
- GROUP BY
- ORDER BY
- DISTINCT counts
- Window functions
- RANK()
- PARTITION BY

3. Power BI — Interactive Dashboard

Created an interactive dashboard showing:

- Total Sales
- Total Profit
- Total Orders
- Total Customers
- Total Products
- Sales Trend
- Sales by Region
- Sales & Profit by Category
- Top 10 Products
- Profit by Sub-Category

Interactive filters:
- Year
- Region
- Category

💡 Key Business Insights

- Technology generated the highest sales among the major categories.
- Some products generate high sales but comparatively lower profit.
- Regional performance varies across the business.
- Higher discount levels can negatively affect profitability.
- A small group of products contributes significantly to overall sales.
